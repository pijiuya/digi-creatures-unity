本目录存放客户交付和现场部署时最常用的资料。

## 文件

- [DigiCreatures Agent 技术流程图](DigiCreatures_Agent_Technical_Workflow_CN.png)

## 使用建议

1. 先把 PDF 发给第一次接入插件的 Unity 用户，用于安装、模型配置、灵魂文件、语义物体和 NavMesh 配置。
2. 把技术流程图放在汇报、演示或 README 中，帮助客户理解运行时闭环。
3. 客户现场需要本地 Codex 协助唤醒服务、检查项目或分析烟测报告时，直接使用 Codex 运行手册里的提示词模板。
